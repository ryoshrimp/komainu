# komainu

The facade crate: a builder that wires the other crates into an embeddable authorization server.

This crate is part of [komainu](https://github.com/ryoshrimp/komainu), an embeddable OAuth 2.0 authorization server. Most applications should depend on the facade crate [`komainu`](https://crates.io/crates/komainu) instead of using this crate directly.

See the [repository](https://github.com/ryoshrimp/komainu) for documentation.
